# ADR-0001：Git では設計文書のみを管理する

- 状態：提案（この PR のマージで採用）
- 日付：2026-11-03

## 背景

このリポジトリは公開されている。一方、AI Memory Archive が扱う会話の原本や抽出した記憶には、個人的な会話、記録の持ち主自身や第三者の個人情報が含まれる。過去の会話には、API キーやパスワードなどの秘密情報が貼り付けられている可能性もある。

Git は、一度コミットしたものを履歴から完全に消すのが難しい。公開リポジトリでは、一度公開された内容を取り消すことはできないと考える必要がある。

## 決定

1. このリポジトリで管理するのは、**設計文書、設計判断の記録、将来の変換・検証スクリプトとそのテスト**に限る。
2. 次のものはコミットしない。Issue や Pull Request にも書かない。
   - 会話の原本・エクスポート（L0-R / L0-S）、正規化データ（L1）、抽出した記憶（L2）、注記・訂正（L3）
   - 個人情報、第三者の情報、手紙や会話の引用
   - API キー、暗号鍵、パスワード、トークンなどの秘密情報
3. テストに使うデータは、**合成データ**のみとする。
4. 誤ってコミットしにくくするため、`.gitignore` で、エクスポートや記録の置き場、鍵ファイルなどを除外する。ただし `.gitignore` は補助であり、確認の責任はコミットする人にある。

## 結果

- 記録そのものは、このリポジトリとは別の、非公開の場所で管理する。その保存先と方式は未決（[アーキテクチャ](../architecture.md) §8）。
- 設計の議論は公開で行えるが、具体例は合成データで示す。
- 誤って秘密情報をコミットした場合は、履歴の書き換えだけで済ませず、その秘密情報自体を無効化する（キーの再発行など）。

## 検討した他の案

| 案 | 判断 |
| --- | --- |
| 記録も同じリポジトリで暗号化して管理する | 鍵の漏えいや将来の暗号の弱体化に対して、公開リポジトリの履歴は取り消せないため採用しない |
| 記録用に非公開リポジトリを別に作る | Git は大量のファイルや個別削除に向かないため、保存先の候補の一つとして未決事項に含める |
