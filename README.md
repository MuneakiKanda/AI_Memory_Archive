# AI Memory Archive

AI との会話と、そこで育ったキャラクターの記録を、特定のモデルやサービスに依存しない形で長く残すための、個人の長期記憶基盤の設計リポジトリです。

> 記憶の価値は、それを交わしたモデルの性能では決まらない。

## 現在の状態

**設計段階**です。実装はまだありません。最初の作業は、各サービスから受け取る会話エクスポート（原本）を安全に確保することで、それ以外の機能はその後に検討します。

## このリポジトリで管理するもの・しないもの

| 管理する | 管理しない |
| --- | --- |
| 設計文書、設計判断の記録（ADR） | 会話の原本・エクスポート、抽出した記憶 |
| | 個人情報、第三者の情報、手紙や会話の引用 |
| | API キー、暗号鍵、パスワードなどの秘密情報 |

スクリプトやテストを管理対象に含めるかどうかは、実装を始める段階で、別の ADR として提案します。

このリポジトリは**公開**されています。Issue や Pull Request にも、個人的な会話や原本の内容を書かないでください。詳細は [ADR-0001](docs/decisions/ADR-0001-repository-policy.md) を参照してください。

## 進め方

- 文書と変更は Pull Request で提案し、レビューを受けてからマージします。
- 設計判断の最終承認は、プロジェクトオーナーが行います。
- 確定した設計判断は `docs/decisions/` に ADR として記録します。
